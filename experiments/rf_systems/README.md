# RF Systems (docs & manifests only)

This area scaffolds **future** radio-frequency sensing / adaptive spectrum experiments.

## Status

- **Implemented:** directory layout, experiment manifest example, hardware/firmware/acquisition/analysis placeholders.
- **Not implemented:** data collection, model training, published numeric results.
- **Do not fabricate results.**

## Spectrum / legal disclaimer

Radio transmission and reception are regulated. Any future RF work must comply with applicable spectrum law (e.g. FCC / NTIA in the US), licensed or explicitly unlicensed bands, power limits, and institutional policies. Passive sensing and simulation are preferred for early research. This repository does **not** authorize unlawful transmission.

## Layout

- `hardware/` — notes on SDRs / antennas (empty placeholders)
- `firmware/` — firmware notes
- `acquisition/` — capture pipeline sketches
- `analysis/` — analysis sketches
- `experiments/` — experiment-specific notes
- `experiment_manifest.example.yaml` — template only
