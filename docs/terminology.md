# Terminology

| Term | Operational meaning |
|------|---------------------|
| **Population** | Single registry of agents; all lifecycle ops use this object |
| **Genome** | Bounded numeric traits → phenotype |
| **Phenotype** | Expressed observe/intervene/learn/explore/validate parameters |
| **Birth Control** | Eligibility, parent selection, cull, birth, lineage, extinction floor |
| **Vision** | Observational evidence channel (not automatic correctness) |
| **Guarded Seer** | Hypothesis authority gated by validation window + MTC + expiry |
| **Reward decomposition** | Correctness, consequence, observation/intervention/fallback costs |
| **OOM failure** | Regime whose optimal action contradicts the in-model obs→action mapping (TLP: `silent_threat`) |
| **Baseline** | Established algorithm used as reference |
| **Simplified** | Deliberately reduced variant (documented) |
| **Deferred** | Concept documented but not executable in this release |
